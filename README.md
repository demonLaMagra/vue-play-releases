# VuePlay releases

This repository publishes VuePlay installer packages and update metadata for packaged ARM64 Linux builds. The VuePlay application source remains in the private `vue-play` repository.

Release assets are generated by the private source repository's ARM64 release workflow. Do not add source code, credentials, or private user data here.

For Raspberry Pi OS 64-bit, download the ARM64 `.deb` installer from a release. AppImage builds are also provided for compatible ARM64 Linux desktops.
